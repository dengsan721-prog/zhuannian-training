# 幸福驿站转念训练 Apple 风 UI 优化设计

日期：2026-08-07

## 目标

把现有页面从“能用的训练工具”提升为“看起来值得信任、愿意继续用的移动端产品”。方向参考苹果公司的设计美感：克制、干净、轻盈、有秩序、有高级感，但不增加用户操作复杂度。

本次只做视觉与体验质感优化，不改变核心业务流程：

- 用户仍可从入班页点击“无需班级码，直接体验”进入 12 个转念场景。
- 12 个转念场景、点评工具、基础训练逻辑不新增复杂步骤。
- 移动端优先，页面宽度继续控制在单手可读范围。

## 视觉方向

采用“苹果式轻奢克制版”：

- 背景：从单一米白升级为柔和浅色渐变，营造安静、温暖、清透的底色。
- 卡片：使用更大的圆角、细边框、柔和阴影和轻微玻璃感，减少粗糙的表格感。
- 字体：继续使用系统字体栈，标题加大字重与行距层次，正文保持高可读性。
- 按钮：主按钮采用 iOS 风格胶囊圆角、轻微高光和按压反馈；次按钮保持轻盈。
- 场景卡片：强化“可点击卡片”的高级感，类似 Apple Health / Apple Music 的清爽卡片，而不是普通列表。
- 色彩：主色保留幸福驿站的温润绿色，但降低厚重感，搭配浅青、米白、暖白、少量金色高光。

## 重点页面

优先优化三个用户最先看到、最影响信任感的页面：

1. 入班页 / 无班级码入口
   - 强化标题区层次，让用户第一眼知道“这是转念训练工具”。
   - “无需班级码，直接体验”按钮要更醒目、更像推荐入口。
   - 保留隐私、服务边界等必要说明，但降低视觉噪音。

2. 12 个转念场景页
   - 让“从痛苦到幸福的12个转念密码”更像产品首页。
   - 分类按钮做成柔和胶囊 tab。
   - 场景卡片做成可触摸的精品卡片，突出场景痛点与幸福密码。

3. 点评工具页
   - 统一背景、卡片、按钮、输入框风格。
   - 输入区域要像一个安静的创作面板，不像普通表单。

## 样式实现范围

主要修改：

- `src/styles/tokens.css`
- `src/styles/global.css`

必要时只做极少量组件 class 调整；不重构业务逻辑，不改数据模型。

## 交互细节

- 所有按钮与卡片保留 44px 以上触控高度。
- 增加轻微 hover / active / focus-visible 状态。
- 不加入复杂动画，只使用短、轻、低干扰的过渡。
- 保持当前移动端紧凑排版，不做过度留白。

## 验证标准

完成后需要验证：

- `npm run lint`
- `npm run typecheck`
- `npm run build:pages`
- 关键页面可访问：入班页、无班级码体验、12 场景页、点评工具页

视觉验收标准：

- 第一眼更像一个认真打磨过的移动端产品。
- 页面仍简单、易懂、低门槛。
- 不因美化牺牲文字可读性和触控便利性。
- 用户能更自然地点击“无需班级码，直接体验”。

## 不做事项

本轮不做：

- 新排行榜、勋章、后台功能。
- 新业务流程。
- 大规模组件重构。
- 桌面端复杂布局。
- 依赖新增 UI 框架。

本轮的价值是先把“门面”和“使用质感”拉起来，让产品看起来更高级、更可信、更愿意被分享。
